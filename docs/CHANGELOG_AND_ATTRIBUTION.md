# Project history and contributions

The work behind this repository spans a coursework project, a conference paper, and a later independent implementation. They are related, but they are not the same codebase.

### 2024 — Coursework and experiments

At the University of Manitoba, Jing Xiang Ong and Abhinav Jain explored S&P 500 data, macroeconomic indicators, technical analysis, and forecasting models.

Jing Xiang wrote the original `coding.ipynb`, which focused on data preparation, exploratory feature engineering, and charts. The other experimental notebooks (`RoughCode1` through `RoughCode4` and `roughCode5`) were collaborative work with Abhinav, who led much of the model-training code and results writing. Those notebooks are not distributed in this repository.

### 2025 — IEEE BigData paper

The research contributed to *Machine Learning on Big Economic Data for Predictive Financial Analytics*, published with Abhinav Jain, Carson K. Leung, Thanh Trung Jack Nguyen, Jing Xiang Ong, and Alfredo Cuzzocrea. See [`paper/citation.bib`](../paper/citation.bib) for the citation.

### 2026 — New reference implementation

The notebooks and modules under [`reproduction/`](../reproduction/) revisit selected parts of the work with a next-session target, chronological splits, and a last-close benchmark. This code was developed separately, with coding assistance and automated tests using synthetic data.

It has not reproduced the paper's results, and it should not be cited as the original source for the published figures or performance tables. The distinction also keeps the 2024 research contributions clear.
